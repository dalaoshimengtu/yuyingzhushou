# 语音控制绘图工具 - 完整指令集

## 说明

- 默认单位为**毫米**，如需使用像素请明确说"像素"或"px"
- 每个绘制的图形自动分配编号（从 #1 开始），编号标签显示在图形上方
- 图形与层一一对应，每层只保留图形的**最终状态**，各层操作互不影响
- 画布显示的是所有可见层的**叠加效果**
- 即使图形被删除，层仍保留在记忆中，可按编号恢复和修改

## 4. 组合命令

使用**和**、**以及**、**再**、**然后**、**接着**等连接词组合多个绘制指令。

| 示例指令 | 解析结果 |
|---------|---------|
| "画一个圆和一个三角形" | 绘制圆(#1) + 三角形(#2) |

## 10. 辅助说明

### 10.1 单位换算

- 默认单位：**毫米** (mm)
- 换算关系：1mm = 3.78px
- 明确指定像素：说"像素"或"px"

| 指令 | 实际像素值 |
|------|-----------|
| "半径50" | 189px (50 × 3.78) |
| "半径50像素" | 50px |
| "宽100高80" | 宽 378px × 高 302px |
| "宽100px高80px" | 宽 100px × 高 80px |

### 10.2 坐标格式

| 格式 | 示例 |
|------|------|
| 坐标 | 坐标50,100 / 坐标 50 100 |
| 位置 | 位置(50,100) / 位置50,100 |
| x,y | x=50,y=100 / x:50 y:100 |

### 10.5 层记忆机制

```
画布 = 所有可见层的叠加效果

层#1: 圆形 {cx, cy, radius=50, color=black}  visible=True
层#2: 矩形 {cx, cy, w, h, color=red}          visible=True
层#3: 三角形 {cx, cy, side=100}               visible=False (已删除)

操作层#1 → 只修改层#1的属性，不影响其他层
操作层#3 → 先重建到画布，再修改，不影响其他层
删除操作 → 隐藏层（visible=False），不删除层数据
```
