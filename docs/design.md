# 语音控制绘图工具 - 设计思路文档

## 1. 项目概述

本项目是一款**语音控制**的绘图工具，用户通过麦克风说出自然语言指令即可完成绘图、修改、删除等操作。系统采用管道式架构，将语音逐步转换为绘图动作，并支持图形层记忆机制，实现对每个图形的独立持久化管理。

## 2. 系统架构

### 2.1 数据流

```
语音输入 ──> 语音识别 ──> AI理解 ──> 命令解析 ──> 绘图执行 ──> 画布窗口
              FunASR    Ollama/规则    Parser     DrawingEngine
               │           │            │              │
               v           v            v              v
            识别文本    命令列表      动作列表      图形层记忆
```

### 2.2 模块说明

| 模块 | 文件 | 职责 |
|-----|------|-----|
| 主程序 | `main.py` | 协调各模块，管理主循环和思维链输出 |
| 语音识别 | `voice_recognizer.py` | 麦克风录音 + FunASR 语音转文字 |
| AI 理解 | `ai_understanding.py` | 自然语言 → 标准化命令（Ollama + 规则引擎回退） |
| 命令解析 | `command_parser.py` | 标准化命令 → 可执行动作列表 |
| 绘图引擎 | `drawing_engine.py` | Tkinter 窗口管理、图形绘制/修改/删除、层记忆 |
| 思维链 | `thought_chain.py` | 调试输出系统处理过程 |

### 2.3 模块间契约

| 接口 | 输入 | 输出 |
|------|------|------|
| `VoiceRecognizer.listen()` | 无 | `str` - 识别文本 |
| `AIUnderstander.understand_compound(text)` | `str` | `List[Dict]` - 命令列表 |
| `CommandParser.parse(cmd)` | `Dict` | `List[Dict]` - 动作列表 |
| `DrawingEngine.execute_action(action)` | `Dict` | 无（直接操作画布） |

## 3. 核心设计

### 3.1 语音识别层

**技术选型：FunASR (Paraformer)**

- 阿里达摩院开源中文语音模型
- 自动将中文数字转为阿拉伯数字（"一百" → "100"）
- 自动添加标点符号
- 首次运行自动下载模型（约 300MB），后续完全离线

**录音机制：**
- 启动时自动检测麦克风设备和采样率
- 使用设备原生采样率录音（通常 44100Hz），通过 scipy 重采样至 16000Hz
- 录音时长默认 10 秒
- 将录音保存为临时 WAV 文件传入 FunASR 识别
- 识别结果从列表格式 `[{'key': 'xxx', 'text': '画一个圆。'}]` 中提取

### 3.2 AI 理解层

**双引擎架构：Ollama LLM 优先 + 规则引擎回退**

```
输入文本 ──> 尝试 Ollama (qwen3.5:0.8b) ──> 解析 JSON 命令
                       │ 失败/超时(8s)
                       v
                  规则引擎
```

**规则引擎处理流程：**

```
原始文本 → 同音词纠正 → 中文数字转换 → 编号操作检测 → 系统命令 → 删除检测
           → 绘制检测 → 修改检测 → 操作检测 → 选择检测
```

**关键设计决策：**

1. **优先级排序**：编号操作 > 系统命令 > 删除 > 绘制 > 修改 > 操作。避免"删除长方形"被误识别为"绘制长方形"。

2. **同音词纠正**：内置 40+ 组常见语音识别同音词映射（"半斤"→"半径"、"巨形"→"矩形"等），在数值提取前执行。

3. **中文数字转换**：支持"五十"→50、"一百"→100、"两百"→200、"三百二十"→320，以及带连接词的格式（"半径为五十"、"半径是两百"）。

4. **组合命令分割**：按连接词（和/以及/再/然后/接着）分割文本，为缺少动词的部分自动补"画"。

5. **默认单位毫米**：所有数值默认视为毫米，自动乘以 3.78 转换为像素。明确说"像素/px"时不转换。

6. **降级策略**：Ollama 不可用时自动回退到规则引擎，不影响基本功能。

### 3.3 命令解析层

将标准化命令拆解为绘图引擎可执行的动作列表：

| 命令类型 | 动作名 | 说明 |
|---------|--------|------|
| draw (circle) | `draw_circle` | 绘制圆形 |
| draw (rect) | `draw_rect` | 绘制矩形 |
| delete (delete_shape) | `delete_shape` | 按类型删除 |
| delete (delete_last) | `delete_last` | 删除最后一个 |
| modify (change_color) | `modify_change_color` | 变色 |
| operation (move) | `op_move` | 移动 |
| operation (rotate) | `op_rotate` | 旋转 |
| delete_by_id | `delete_by_id` | 按编号删除 |
| modify_by_id | `modify_by_id` | 按编号修改 |

### 3.4 绘图引擎层

#### 3.4.1 图形层记忆机制（核心设计）

```
ShapeLayer (层记忆，永不删除) ──> DrawingShape (画布上的可见对象)
      │                                  │
      │ 保存图形的最终状态                 │ 仅保留可见图形
      │ 包含: shape_id, shape_type,        │ 从 ShapeLayer 派生
      │       props, visible, canvas_ids   │ 包含: canvas_ids, label_id
      │                                  │
      └── 支持按编号恢复和修改 ──────────┘
```

**设计原则：**
- 每个绘制的图形创建一个 `ShapeLayer`，保存在 `self.layers` 列表中
- 层只保留图形的**当前最终状态**（不保留历史状态）
- 删除操作只是将层标记为 `visible = False`，**层数据不会被删除**
- 画布显示的是所有可见层的**叠加效果**
- 每层操作**完全独立**，修改一个层不影响其他层（props 和 canvas_ids 均为独立副本）

**按编号操作流程：**
```
"修改图形3" → _find_shape_by_id(3) → 可见? → 是 → 直接操作
                                    → 否 → _find_layer_by_id(3)
                                          → _restore_layer_to_canvas(layer)
                                          → 重建到画布 → 操作
```

#### 3.4.2 支持的图形类型

| 类型 | shape_type | 绘制方法 | 属性参数 |
|------|-----------|---------|---------|
| 圆形 | circle | `_draw_circle` | cx, cy, radius |
| 椭圆 | ellipse | `_draw_ellipse` | cx, cy, rx, ry |
| 矩形 | rect | `_draw_rect` | cx, cy, x0, y0, x1, y1, w, h |
| 三角形 | triangle | `_draw_triangle` | cx, cy, side |
| 线段 | line | `_draw_line` | x1, y1, x2, y2 |
| 箭头 | arrow | `_draw_arrow` | cx, cy |
| 五角星 | star | `_draw_star` | cx, cy, size |
| 多边形 | polygon | `_draw_polygon` | cx, cy, side_count, size |

#### 3.4.3 撤销/重做机制

- 使用 `self.history` 保存层状态快照（序列化后的 `ShapeLayer.to_dict()`）
- 撤销时：将当前状态压入 `redo_stack`，从 history 弹出，重建画布
- 重做时：从 `redo_stack` 弹出，压入 history，重建画布
- 撤销/重做后从层状态重建可见图形和画布元素

#### 3.4.4 旋转实现

- 以图形**自身几何中心**为旋转原点
- 在二维平面上绕 z 轴旋转
- 使用标准旋转矩阵：`nx = x*cos_a - y*sin_a + cx, ny = x*sin_a + y*cos_a + cy`
- Tkinter Canvas 坐标系 y 轴向下，标准矩阵实现**顺时针旋转**

#### 3.4.5 编号标签

- 每个图形绘制后自动分配唯一编号（从 #1 开始）
- 编号以红色 `[1]` 标签形式显示在图形上方居中位置
- 移动/旋转操作时编号标签跟随图形一起移动
- 支持"隐藏编号"/"显示编号"指令全局控制

## 5. 响应延迟

| 阶段 | 预估延迟 | 说明 |
|-----|---------|------|
| 语音录制 | 1-10 秒 | 取决于说话时长 |
| 语音识别 (FunASR) | 0.1-1 秒 | CPU 本地推理 |
| AI 理解 (Ollama) | 1-5 秒 | GPU 更快，超时 8s 回退规则引擎 |
| AI 理解 (规则引擎) | < 1ms | 纯本地匹配 |
| 命令解析 | < 1ms | 纯本地匹配 |
| 绘图执行 | < 50ms | Tkinter 本地绘制 |
| **总延迟** | **1-16 秒** | 主要取决于录音时长和 Ollama 推理 |

## 6. 技术栈

| 技术 | 用途 | 选型理由 |
|-----|------|---------|
| Python 3.8+ | 开发语言 | 跨平台，生态丰富 |
| FunASR (Paraformer) | 语音识别 | 中文识别最佳，自动数字转换，完全离线 |
| Ollama + Qwen3.5 | AI 理解 | 本地大模型，无需联网，中文理解强 |
| Tkinter | GUI 绘图 | Python 内置，零依赖 |
| Pillow | 截图保存 | 轻量级图像处理 |
| PyAudio | 麦克风采集 | 跨平台音频录制 |
| scipy | 音频重采样 | 高质量采样率转换 |

## 7. 关键设计决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| 语音引擎 | FunASR 替代 Vosk | 中文识别精度更高，自动数字转换，自动标点 |
| AI 理解 | Ollama + 规则回退 | LLM 理解能力强，规则引擎保证可用性 |
| 默认单位 | 毫米而非像素 | 更贴近日常表达习惯 |
| 图形管理 | 层记忆机制 | 支持删除后按编号恢复和修改 |
| 旋转中心 | 图形自身中心 | 符合直觉，不影响其他图形 |
| 组合命令 | 规则分割而非 LLM | 速度快，可控性强，LLM 作为可选增强 |
